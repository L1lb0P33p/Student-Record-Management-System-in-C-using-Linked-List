# Student-Record-Management-System-in-C-using-Linked-List
A menu-driven Student Record Management System developed in C using Singly Linked List Data Structure. This project allows users to add, delete, modify, display, sort, reverse, save, and load student records with automatic roll number generation and file handling.
Student Record Management System

This project is a menu-driven application developed in C using Singly Linked List. It provides an efficient way to manage student records through various operations such as adding, deleting, modifying, displaying, sorting, reversing, saving, and loading records.

Features:
• Add new student records
• Auto-generate unique roll numbers
• Delete records by Roll Number or Name
• Modify student details
• Display all student records
• Sort records by Name or Percentage
• Reverse the linked list
• Delete all records
• Save records to a file
• Load records from a file during program startup
• Percentage validation (0–100)

Technologies Used:
• C Programming
• Singly Linked List
• File Handling
• Dynamic Memory Allocation
• Linux/GCC

File Structure:
• main.c
• student.h
• stud_add.c
• stud_del.c
• stud_mod.c
• stud_show.c
• stud_sort.c
• stud_reverse.c
• stud_deleteall.c
• stud_save.c
• stud_load.c

Compilation:
make

Run:
./outfile

This project demonstrates the practical implementation of Linked Lists, File Handling, Dynamic Memory Allocation, and Modular Programming concepts in C.
